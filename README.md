Rock Paper Scissors

Overview

A command-line-style Rock Paper Scissors game developed using JavaScript as part of my journey toward becoming a software engineer.

The project focuses on applying fundamental JavaScript concepts to create an interactive game where a player competes against a computer opponent.

Technologies Used

JavaScript

Git

GitHub

Features

Player-versus-computer gameplay

Randomized computer selections

Win, loss, and tie detection

User input validation

Case-insensitive player input

Handling invalid inputs and canceled prompts

Challenges and Solutions

One of the challenges I encountered was handling unexpected user input.

During testing, I discovered that canceling the input prompt could cause issues with the game's behavior.

I investigated the problem and improved the input-handling logic using a do...while loop, a null check, and the toLowerCase() method.

This experience reinforced the importance of testing edge cases, debugging, and writing code that handles unexpected user behavior.

How to Run

This project uses JavaScript browser prompts and the developer console.

Download or clone the repository.

Open the project's HTML entry point in a web browser, if provided.

Open the browser's developer console.

Follow the game's prompts to play Rock Paper Scissors.
